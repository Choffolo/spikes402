# Software bill of materials

CycloneDX JSON SBOMs are generated by [`scripts/sbom.sh`](../scripts/sbom.sh)
and published as artifacts of the `sbom` GitHub Actions workflow:

- `spikes402-source.cdx.json` — Go module, browser extension npm dependencies
  (including devDependencies), and GitHub Actions used in workflows
- `spikes402-image.cdx.json` — the runtime Docker image (the Go binary and
  the distroless base)

Run `./scripts/sbom.sh` to produce them locally. Vulnerability status is
recorded in [`vex/spikes402.openvex.json`](../vex/spikes402.openvex.json).
See [SECURITY.md](../SECURITY.md#software-bill-of-materials-and-vex).
