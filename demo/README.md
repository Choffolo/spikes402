# spikes402.dev origin

Static files for the public demo at [spikes402.dev](https://spikes402.dev/).
The home page is free; `/extension/` explains how to install the wallet;
`/privacy/` is the wallet privacy policy (also free);
`/premium/` is the path protected by Spikes402.

Copy `site/` to the demo origin (on the current VPS, `/opt/spikes402/site`).
This folder is the source of truth in git; it is not deployed automatically.
